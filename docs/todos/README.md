# TODO Documents

This folder contains phase-level TODO documents.

## Purpose

Before implementation starts for a new phase, create a TODO document here so the work has a stable checklist separate from the rolling worklog.

## Naming

Use this format:

```text
phase-N-short-name.md
```

Examples:

- `phase-2-slug-group-api.md`
- `phase-3-quiz-api.md`
- `phase-4-public-embed-api.md`

## Required Sections

Each phase TODO document should include:

- source documents
- scope
- out of scope
- implementation checklist
- verification checklist
- handoff notes
