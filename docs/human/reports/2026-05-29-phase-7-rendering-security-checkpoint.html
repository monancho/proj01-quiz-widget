Phase 7 Rendering/Security Checkpoint

Markdown/LaTeX rendering and basic content-safety handling were added for both the public iframe and admin surfaces.

Date: 2026-05-29 Branch: feature/rendering-security Status: Locally verified

What Changed

  • Added a shared RichText renderer for Markdown, GFM, inline math, and block math.
  • Applied the renderer to public quiz questions, choices, correct answers, and explanations.
  • Applied the same renderer to admin quiz table text and the admin quiz preview.
  • Blocked raw HTML rendering and unsafe link protocols such as javascript:.
  • Lazy-loaded admin/embed route pages to keep route chunks separated.

Verification

  • npm.cmd run build passed in client/.
  • Public iframe rendered Markdown bold text and KaTeX math.
  • Admin quiz table rendered Markdown and KaTeX through the same renderer.
  • Unsafe test content did not leave script tags, event-handler attributes, or javascript: links in quiz/admin content.
  • Mobile iframe QA at 390px width reported no horizontal overflow.

Review Notes

The current approach is intentionally simple: stored quiz strings remain plain text, and rendering happens only in the frontend. A rich text editor can be considered later if writing Markdown directly becomes inconvenient.
