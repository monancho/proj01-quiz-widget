공개 API 정책

  • 응답은 문제 객체 배열만 반환합니다.
  • 배너 정보와 메타데이터 wrapper는 포함하지 않습니다.
  • Slug Group이 없거나 비공개이거나 3문제 미만이면 200 OK와 []를 반환합니다.
  • 공개 완료된 Slug Group은 sortOrder 순서의 문제 3개를 반환합니다.
