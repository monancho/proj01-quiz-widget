관리자 화면과 공개 iframe 위젯을 컴포넌트 단위로 분리해 검토한 보고서입니다. 이번 작업은 기능 추가나 코드 변경 없이 현재 상태를 평가하고 후속 개선 우선순위를 정하는 데 목적이 있습니다.

Overall Result

Stable Areas

주요 흐름은 동작하고 레이아웃 붕괴는 발견되지 않았습니다.

  • 관리자 데스크톱과 모바일 모두 가로 오버플로우 없음.
  • 공개 iframe은 투명 배경 유지.
  • 답 선택, 오답/정답 피드백, 다음 문제, 최종 결과 흐름 정상.
  • 라이트/다크 테마 기본 색 대비는 안정적입니다.

Main Risks

서비스 수준으로 다듬으려면 모달, 모바일 밀도, CSS 구조를 먼저 봐야 합니다.

  • 퀴즈 수정 모달과 iframe 유틸리티 모달이 데스크톱에서도 거의 전체 높이를 사용합니다.
  • 관리자 모바일은 기능은 보이지만 세로 스크롤 부담이 큽니다.
  • styles.css의 중복 레이어가 많아 시각 변경의 예측 가능성이 낮습니다.

Recommended Direction

새 기능보다 정보 구조와 밀도 조정 중심으로 후속 작업을 나누는 편이 좋습니다.

  • 모달 레이아웃 경량화.
  • 관리자 모바일 전용 정보 우선순위 조정.
  • iframe 상태별 QA 체크리스트를 정식화.

QuizCard / choices Good 선택 전 버튼 비활성, 답 선택 후 정답/오답 표시, 피드백 연결이 정상입니다. 긴 Markdown/LaTeX 선택지와 이미지 없는 긴 텍스트 케이스 QA 추가.

RichText Good HTML은 건너뛰고 안전한 URL만 허용합니다. Markdown/LaTeX 표시를 공통 컴포넌트로 처리하는 점도 좋습니다. 긴 수식의 가로 스크롤/줄바꿈 QA 유지.
